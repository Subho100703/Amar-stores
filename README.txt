AMAR STORE - STARTER APP

চালু করার নিয়ম (Windows 11):
1. ZIP ফাইল Extract করুন।
2. amar_store_app ফোল্ডারের ভিতরে index.html ফাইলটি খুঁজুন।
3. index.html-এ ডাবল ক্লিক করুন। Chrome/Edge-এ খুলবে।
4. উপরের Admin বাটনে গিয়ে পণ্য যোগ/পরিবর্তন/মুছতে পারবেন।
5. Backup Export দিয়ে পণ্যের তথ্য JSON ফাইলে সংরক্ষণ করুন।

গুরুত্বপূর্ণ সীমাবদ্ধতা:
- এটি একটি প্রাথমিক frontend demo; কোনো server/database নেই।
- ডেটা শুধু যে browser/device-এ ব্যবহার করছেন তার localStorage-এ থাকবে।
- Browser data clear করলে তথ্য হারাতে পারে; নিয়মিত Backup Export করুন।
- Admin-এ নিরাপদ password/login নেই। এটি public live store হিসেবে প্রকাশ করবেন না।
- প্রকৃত online business-এর জন্য backend, database, secure admin login, hosting,
  payment gateway, shipping integration, customer order form এবং privacy/return policies
  যুক্ত করতে হবে.
